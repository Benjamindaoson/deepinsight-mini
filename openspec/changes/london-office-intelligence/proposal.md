## Why
Asset management teams need a traceable briefing on London office developments without repeating manual searches. The recruitment assessment requires an interactive Python agent and a concise business presentation, supported by actual execution evidence.

## What Changes
- Build an isolated FastAPI/SQLite product in D:\deepinsight-mini.
- Collect public primary sources, retain versions, detect updates and compare approved observations deterministically.
- Add one bounded model SDK tool-calling agent with six shared skills.
- Produce HTML, email and PDF from a single saved report object.
- Provide London-time scheduling, safe notification delivery, five business pages and a five-slide PPTX.

## Capabilities
### New Capabilities
- `market-intelligence`: Evidence collection, monitoring, interactive research, reporting and delivery.
### Modified Capabilities
None.

## Impact
New Python source, project-local virtual environment, SQLite, deployment scripts and acceptance evidence. No writes to DeepInsight Lite. No autonomous fact approval or external notification without explicit opt-in.
