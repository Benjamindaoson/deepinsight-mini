## Why

The existing runnable PoC has six ad hoc tools, candidate inspection and a durable OS-triggered monitor. Existing sources and pending observations must remain unapproved unless individually reviewed.

## What Changes

- Add a read-only SQL semantic layer with structured, validated queries and provenance-preserving trend, coverage and regional operations.
- Register eight executable domain skills with shared Pydantic results, permissions and optional MCP protocol adapter.
- Add linked ECharts dashboard filters, evidence drill-down and contextual Ask AI links; approved data is the default.
- Add an APScheduler 3 worker around the existing persistent slot/monitor pipeline.
- Expose requested API contracts using existing storage, report and notification services.
- Verify real provider, collection, scheduled execution, browser interactions, PDF and loopback delivery. Explicitly mark unresolved business evidence or provider failures.
